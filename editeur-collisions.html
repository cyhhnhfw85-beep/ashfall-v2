ASHFALL — EDITEUR DE COLLISIONS

Ce document affiche le véritable fond et le fichier masque utilisé par le moteur.

Bleu = obstacle infranchissable. Sol non coloré = traversable. Dessine directement avec le doigt ou la souris. Pour les murs, conserve le périmètre bloqué ; les portes réelles sont traitées dans le moteur.

Pour intégrer une correction, exporte le PNG et remplace le fichier assets/fixedworld/masks/XX.png portant le même numéro, sans le redimensionner.

Le jeu affiche précisément ce masque avec la touche C sur ordinateur, ou avec le paramètre ?collisionDebug.

Les masques livrés ici proviennent des contours V6.3. Ils constituent un point de départ à affiner, et non une certification de précision au pixel près.
